values that winch reads from each host

Facts are values that winch reads from each host before the plan, such
as the OS release.

Reading a fact:
  Expressions read a fact as facts.os.id, and templates as
  {{ .facts.os.id }}. Facts are a fixed set. A read of an unknown fact
  is an error.

When winch reads them:
  winch reads the facts once per host per run, before the first step,
  and again after a reboot. They describe the host before the run.

Example:
  # winch.yaml
  name: demo
  hosts:
    web1.example.com: {}
  steps:
    - recipe: base
  recipes:
    base:
      require:
        - !expr facts.os.id == "debian" and facts.os.version == "13"
      steps:
        - reboot:
            if_required: true
          when: !expr facts.reboot_required
